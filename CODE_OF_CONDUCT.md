# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. In short: be respectful, assume good faith, welcome newcomers, and
criticise ideas rather than people. Harassment of any kind is not tolerated.

Project-specific expectations:

- Discussions of sanctions, named persons and evasion techniques stay factual and
  professional. Never post real payment data or personal data of customers.
- Reports of screening evasion patterns are welcome and are handled as security reports
  (see [SECURITY.md](SECURITY.md)), not as public issues.

## Enforcement

Report unacceptable behaviour privately to the maintainers. All reports are reviewed and kept
confidential. Maintainers may remove contributions or block participants who violate this code,
following the Contributor Covenant's enforcement guidelines.
